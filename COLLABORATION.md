# Совместная работа над сценами

## Как устроен проект

- `src/landing/` — общее стартовое меню с шестью кнопками.
- `src/app/sections.js` — названия кнопок и адреса сцен.
- `src/app/router.js` — переключение между меню и сценами.
- `src/scenes/<id>/` — независимый код конкретной сцены.
- `public/scenes/<id>/` — изображения, видео и другие материалы конкретной сцены.
- `src/shared/` — нейтральные общие стили и небольшие переиспользуемые помощники.

## Как работать над одной сценой

Для своей сцены редактируйте только две папки с одинаковым названием:

```text
src/scenes/<id>/
public/scenes/<id>/
```

В `index.js` лежат разметка и поведение сцены, а в `style.css` — только её стили. Изображения подключаются по пути вида `/scenes/recognition/filename.png`.

| Кнопка | ID папки |
| --- | --- |
| Узнавание | `recognition` |
| Разговор | `conversation` |
| Помощь | `help` |
| Границы | `boundaries` |
| Поддержка себя | `self-support` |
| Разделение ответственности | `responsibility` |

## Правила, чтобы не мешать друг другу

1. Каждый берёт отдельную сцену и работает только в её папках.
2. Не меняйте `src/app/`, `src/landing/` и `src/shared/` без предварительной договорённости: это общая инфраструктура.
3. Для своей задачи создавайте отдельную ветку, например `feature/recognition`.
4. Перед передачей изменений запускайте `npm run build`.
